Principles

  • Quiet by default: neutral surfaces and 1px borders, with no gradients, glows or emoji. Colour appears only where it carries meaning: app squares, class rails, status tags and one accent for primary actions and focus.
  • One sidebar, plain words: a Notion-style text list with sections (Apps, Planner, Splits, Files). Tools sit at the bottom. The sidebar collapses to icons on narrow windows.
  • The title bar is the toolbar: 40px tall, icons only, with tooltips. Open in browser is a globe, Pop out is an arrow leaving a box, and Split is two columns. Rare actions (Zoom, Screenshot this app, Show in folder) go under More.
  • Today reads like a page, not a dashboard: one column, section headings, list rows and no card grid.
  • Class icons: a set of 12 line icons (code, maths, lab, chart, book, chip, business, writing, languages, discussion, database, music) shown in the class colour. They replace the emoji picker.
  • Motion: only 150 ms hover, toggle and menu fades. The confetti is gone.
