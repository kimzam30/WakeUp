WakeUp v3 · widgets, draft 2

Home-screen widgets, measured

Every widget below is drawn at the size your own launchers hand to a widget, read from the Z Flip and the Tab S9 over adb. One dp is one pixel on this page. Turn on Spacing to see the padding, rows and type boxes. Row counts and the timeline scale are worked out from the size, so what you see is what fits.

The measurements

WhereScreenOne cellDrawn at
Cell and drawn sizeOne UI gives each widget a box of cells and draws standard widgets at 83.3% of it (its own margin). These are the sizes Samsung's weather and photo widgets report on your devices.
ShapeCorner radius 24 dp, One UI's own widget radius on both devices. Things inside use 8 (24 − 16 padding), so the corners stay parallel.
Spacing16 dp padding (12 when the widget is under 160 dp wide), an 8 dp gap, 36 dp rows. Every tap target is at least 36 dp tall and spans the row.
TypeLabel 11 caps, row 13, title 15, hero 28 (34 when the widget is taller than 170 dp). Inter. Times use tabular numbers.

How they adapt

One layout per size bandAndroid 12+ lets a widget give several layouts; the launcher picks by the size it has. WakeUp gives three: under 160 dp wide (compact), 160–300 (regular), over 300 (wide). Resizing a widget switches layout, never squashes it.
Rows from heightLists show ⌊(height − padding − header − gap) ÷ 36⌋ rows; the header carries the total. The timeline fits the day's first to last class into the height it has.
UpdatesAt each class start and end, every 15 minutes, and right after you change something in WakeUp. Android doesn't allow a ticking clock in a widget, so countdowns are in minutes.
Light and darkFollow Android's setting, so they match the rest of your home screen. No glass: widgets sit on your wallpaper.

Decided (Kim: go with the recommendations)

Build order: Next class and Due today firstThen Today, Exam, Focus and the cover screen. Most study and to-do apps lead with the same two: MyStudyLife's widgets show the next class and the tasks due, and Todoist and TickTick both have a task-list widget where you tick things off from the home screen. They're the ones glanced at many times a day.
Home-screen grid: work on any gridOne UI lets you pick 4 or 5 columns. Each widget gets a compact layout for under 160 dp wide, so a 5-column Flip (70 dp cells) still looks right. No setting needed; the launcher's size picks the layout.
Free gaps: say "Free", and name one due taskStructured fills open time with tasks from its inbox. WakeUp doesn't know how long a task takes, so it won't claim one "fits". The gap says "Free 11–1 · Lab 3 report due" when something is due that day, and just "Free 11–1" when nothing is.
Exam widget: follows the next exam, and you can pin oneCountdown widgets usually ask which event to show when you place them; Apple's Up Next style just follows what's next. WakeUp does both: it follows the next exam by default, and placing it offers "Pin an exam" for one you care about most.
